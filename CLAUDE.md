# StandardLibrary

The Fearless `base` package, its Java runtime support (`rt`), and
integration test projects (`integrationTests`).

## Reading the API instead of the full source

Compiling any Fearless package writes two doc files side by side:
`<pkg>.html` (browsable) and `<pkg>.txt` (a minimal plain-text rendering of
the same types/signatures/extends/doc-comments/examples, no links, no
markup — built to be read by a coding agent instead of the HTML or the raw
`.fear` sources, at a fraction of the tokens). When writing Fearless code
against this library, read the `.txt` file for the relevant package before
grepping through `base/**/*.fear`.

Where it lands:
- This library's own `base` package: `dbgOut/baseCache/base.txt`, produced
  by running the Coordinator test suite (`RunIntegration`'s `@BeforeAll`
  calls `mainCoordinator.BaseCacheBuilder.buildInto`) or by building the
  portable/manager app. Missing or older than the last `base/**` change
  means it needs regenerating — run the Coordinator tests once.
- Inside a built portable or manager app: `<appDir>/stdLib/baseCache/base.txt`.
- Any other compiled Fearless project (including the folders under
  `integrationTests/`): `<project>/.fearless_out/gen_java/<pkg>.txt`, one
  per compiled package, next to `<pkg>.html`.

Generated by `Coordinator/src/docBuilder/HtmlDocRenderer.java`
(`renderText()`), invoked from `HtmlDocBuilder.complete()` every time the
HTML doc is written — the two files are always written together.
